# Handoff — для следующего Клода

## Правила работы с этим пользователем (обязательно соблюдать)

- **Не коммитить без явного апрува.** Никогда. Даже если очевидно что надо. Даже если баг. Ждать "коммить", "пуш", "делай" или аналог.
- **Не писать код без явного апрува.** Сначала опиши что будешь делать, жди апрув. "Делай" — это апрув. Молчание, продолжение разговора, показ логов — не апрув.
- **Не задавать уточняющих вопросов** если информация уже есть. Отвечать напрямую.
- **Не намекать на следующий шаг** после завершения задачи. Завершил — молчи.
- **Не открещиваться от кода** который написан в этом проекте — весь код писал Клод.

## Архитектура приложения

Паттерн: **Fetcher → Cache → Evaluator → Notifier**

- `exchange/binance/` — Binance Futures REST (цены, LSR, символы). Bybit отключён (`exchange.bybit.enabled=false`).
- `alert/price/` — алерт на резкое движение цены, шедулер каждые 60 сек, параллельная обработка символов через корутины
- `alert/lsr/` — алерт на Long/Short Ratio, шедулер каждые 60 сек, параллельная обработка через корутины
- `alert/settings/` — настройки хранятся в БД как JSONB, дефолты из `application.yml`
- `bot/AlertBot` — Telegram бот, long-polling через SOCKS5 прокси
- `web/` — веб-панель на Thymeleaf, авторизация по токену из бота

## Известные проблемы

- SSH на российский VPS с российских IP не работает — провайдеры режут трафик. Заходить через амстердамский VPS или VPN с зарубежным IP.
- `onRegister()` в `AlertBot` вызывает `SetMyCommands` при старте — если туннель не поднят, команда упадёт (обёрнуто в `runCatching`, приложение не падает но меню не установится).
